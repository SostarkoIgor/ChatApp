# Chat app

This is a small chat app project where I explored end-to-end encryption and real-time applications.

The project is still a work in progress and currently unfinished.

---

## Features  
- **End-to-End Encryption (E2EE)**: All messages are encrypted on the client side and can only be decrypted by the intended recipient.  
- **Real-Time Messaging**: Powered by SignalR for instant communication.  
- **Secure User Authentication**: Implements robust authentication mechanisms using ASP.NET Identity.  

---

## Technology Stack  

### Frontend  
- **React**: For building the user interface.  
- **React Router**: For client-side routing.  
- **Axios**: For API communication.  

### Backend  
- **ASP.NET Core**: For server-side logic and API endpoints.  
- **SignalR**: For real-time communication.  
- **Entity Framework Core**: For database interactions.
